# HabitMiner: Data Directory 💾

This directory contains local raw datasets and interim processed files.

> [!CAUTION]
> Raw trajectory files (`*.plt`, `*.csv`) and database files (`*.sqlite`, `*.db`) are ignored by `.gitignore` to prevent committing massive dataset files or sensitive location logs into version control.

---

## Directory Hierarchy

```
data/
├── geolife/                # Place raw Microsoft GeoLife dataset here (Data/000/, Data/001/, ...)
└── interim/                # Preprocessed stay_points.csv, semantic_pois.csv generated by engine/
```

For detailed dataset download instructions and parsing specifications, refer to [docs/DATASET.md](../docs/DATASET.md).
